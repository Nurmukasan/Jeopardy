# Halloween Jeopardy

Игра «Своя игра» (Jeopardy) для Хэллоуин-вечеринки по вопросам из сценария `HALLOWEEN_EVENT_SCRIPT.docx`.

## Как запустить

Откройте `index.html` в браузере (двойной клик). Сервер и интернет не нужны, только для шрифтов.
Можно также включить GitHub Pages для этого репозитория (Settings → Pages → ветка, папка `/`).

## Как играть

- Две команды: **Pumpkins** и **Ghosts**. Названия можно изменить, кликнув по ним.
- На доске 16 вопросов (100 / 200 / 300 / 500 очков). Нажмите на клетку, чтобы открыть вопрос.
- **Show answer** (или пробел) подсвечивает правильный ответ.
- **+N Команда** начисляет очки за вопрос, **No one** закрывает вопрос без очков.
- Ошиблись? Откройте сыгранную клетку снова и выберите другую команду: очки перенесутся.
- Кнопки **−100 / +100** под счётом для ручной корректировки.
- **Show results** показывает победителя, **New game** начинает заново.
- Прогресс сохраняется в браузере, обновление страницы игру не сбросит.

Горячие клавиши в окне вопроса: `Пробел` ответ, `1` / `2` очки команде, `0` никому, `Esc` закрыть.

Вопросы и ответы находятся в начале `<script>` в `index.html` (массив `QUESTIONS`).
