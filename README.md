# Halloween Jeopardy

Игра «Своя игра» (Jeopardy) для Хэллоуин-вечеринки по вопросам из сценария `HALLOWEEN_EVENT_SCRIPT.docx`.

## Как запустить

Откройте `index.html` в браузере (двойной клик). Сервер и интернет не нужны, только для шрифтов.
Можно также включить GitHub Pages для этого репозитория (Settings → Pages → ветка, папка `/`).

## Как играть

- Две команды: **Pumpkins** и **Ghosts**. Названия можно изменить, кликнув по ним.
- На доске 16 вопросов (100 / 200 / 300 / 500 очков). Нажмите на клетку, чтобы открыть вопрос.
- **Show answer** (или пробел) подсвечивает правильный ответ.
- **+N Команда** начисляет очки за вопрос, **No one** закрывает вопрос без очков.
- Ошиблись? Откройте сыгранную клетку снова и выберите другую команду: очки перенесутся.
- Кнопки **−100 / +100** под счётом для ручной корректировки.
- **Show results** показывает победителя, **New game** начинает заново.
- Прогресс сохраняется в браузере, обновление страницы игру не сбросит.
- Фон: узор из тыкв, конфет, летучих мышей и вампирских клыков (`assets/halloween-pattern.svg`).

## Скримеры

Иногда (редко) после сыгранного вопроса на весь экран резко, без плавного появления, выскакивает страшное лицо: упырь, череп или демон.
Экран вспыхивает и мигает красным, лицо сильно трясётся, звучит громкий крик с ударом, после скримера трясётся и доска. На телефонах Android ещё и вибрация.
- Не раньше чем через 3 вопроса после предыдущего скримера, затем с шансом 35% после каждого вопроса, через 2–7 секунд.
  В среднем 2–3 скримера за игру.
- Появляются только когда открыта доска, никогда посреди вопроса.
- Кнопка **Scares: on/off** внизу включает и выключает их (настройка запоминается).
- Секретная клавиша для ведущего: `S` (или `Ы` на русской раскладке) на доске запускает скример вручную.
- Звук включается только после первого клика по странице (так работают браузеры), поэтому кликните по сайту перед началом.
- Громкость крика упирается в громкость устройства: выкрутите колонки погромче.

Горячие клавиши в окне вопроса: `Пробел` ответ, `1` / `2` очки команде, `0` никому, `Esc` закрыть.

Вопросы и ответы находятся в начале `<script>` в `index.html` (массив `QUESTIONS`).
